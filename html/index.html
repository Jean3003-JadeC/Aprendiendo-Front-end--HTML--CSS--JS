1. Introducción a HTML

HTML (HyperText Markup Language) es el lenguaje de marcado estándar para crear páginas web. Define la estructura y el significado del contenido web mediante etiquetas.

Estructura básica de un documento HTML

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>
</head>
<body>
    <h1>¡Hola, mundo!</h1>
    <p>Esta es mi primera página web.</p>
</body>
</html>
  • <!DOCTYPE html> — indica al navegador que uses HTML5
  • <html> — la raíz del documento
  • <head> — metadatos, título, enlaces a CSS
  • <body> — todo el contenido visible

2. Sintaxis y Elementos Básicos

Los elementos HTML se escriben con etiquetas que tienen apertura y cierre:

<etiqueta atributo="valor">Contenido</etiqueta>

<!-- Ejemplos -->
<p>Esto es un párrafo</p>
<a href="https://ejemplo.com">Esto es un enlace</a>
<img src="foto.jpg" alt="Descripción">  <!-- Elemento vacío (self-closing) -->
💡 Tip: Los comentarios en HTML se escriben así: <!-- esto es un comentario -->. El navegador los ignora pero ayudan a documentar el código.

3. Encabezados y Párrafos

Los encabezados (h1 a h6) definen títulos y jerarquía. Los párrafos (p) contienen texto común.

h2. Subtítulo

h3. Sección

h4. Subsección

h5. Detalle
h6. Nota

Este es un párrafo normal. HTML ignora los espacios extra y los saltos de línea dentro de un párrafo.

10. Semántica y Accesibilidad

Las etiquetas semánticas describen el significado del contenido, no solo su apariencia. Esto mejora la accesibilidad y el SEO.

<header> — Encabezado de la página
<nav> — Navegación principal
<main> — Contenido principal
<section> — Sección temática
<article> — Artículo independiente
<aside> — Contenido relacionado
<footer> — Pie de página

ARIA básico

Los atributos ARIA mejoran la accesibilidad para lectores de pantalla:

<!-- Atributos ARIA comunes -->
<nav aria-label="Navegación principal">
<button aria-label="Cerrar ventana">X</button>
<div role="alert" aria-live="polite">Mensaje importante</div>
  • aria-label — describe un elemento sin texto visible
  • role — define el propósito del elemento
  • aria-live — notifica cambios a lectores de pantalla

11. Métodos y Buenas Prácticas

  • ✅ Usa indentación consistente (2 o 4 espacios)
  • ✅ Siempre incluye alt en las imágenes
  • ✅ Usa minúsculas para etiquetas y atributos
  • ✅ Cierra siempre las etiquetas (<p></p>, no <p>)
  • ✅ Usa etiquetas semánticas en lugar de <div> cuando sea posible
  • ✅ Valida tu HTML con el validador W3C
  • ✅ Usa entidades HTML para caracteres especiales: &copy; = ©

Entidades HTML comunes

&lt; → < &gt; → > &amp; → & &quot; → " &copy; → © &nbsp; → espacio
