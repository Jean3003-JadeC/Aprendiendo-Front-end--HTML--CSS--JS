¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje de marcado estándar para crear páginas web. Define la estructura y el significado del contenido web.

📊 Tablas en HTML

Las tablas permiten organizar datos en filas y columnas. Se componen de <table>, <tr> (filas), <th> (encabezados) y <td> (celdas).

Ejemplo 1: Tabla básica

Horario de clases
Día Materia Horario Salón
Lunes HTML 9:00 - 10:30 101
Miércoles CSS 9:00 - 10:30 102
Viernes JavaScript 11:00 - 12:30 103
Total: 3 clases por semana
📝 Ver código de la tabla 
<table>
    <caption>Horario de clases</caption>
    <thead>
        <tr>
            <th>Día</th>
            <th>Materia</th>
            <th>Horario</th>
            <th>Salón</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Lunes</td>
            <td>HTML</td>
            <td>9:00 - 10:30</td>
            <td>101</td>
        </tr>
        <tr>
            <td>Miércoles</td>
            <td>CSS</td>
            <td>9:00 - 10:30</td>
            <td>102</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="4">Total: 3 clases</td>
        </tr>
    </tfoot>
</table>

🧪 Ejercicio: Tabla

Crea tu propia tabla con tu horario semanal. Incluye al menos 5 filas y usa colspan en al menos una celda.

💡 Usa <table>, <tr>, <th> para encabezados y <td> para datos. Ejemplo: <td colspan="2">Fusión</td>

📝 Formularios en HTML

Los formularios permiten recolectar datos del usuario. Se crean con <form> y contienen inputs, labels, botones y más.

Ejemplo: Formulario de contacto completo

Información personal
El nombre debe tener al menos 3 caracteres
Ingresa un correo válido
Detalles del mensaje
El mensaje debe tener al menos 10 caracteres
📝 Ver código del formulario 
<form>
    <fieldset>
        <legend>Información personal</legend>

        <label for="nombre">Nombre:</label>
        <input type="text" id="nombre" required>

        <label for="email">Email:</label>
        <input type="email" id="email" required>

        <label for="telefono">Teléfono:</label>
        <input type="tel" id="telefono" pattern="[\+\d\s\-]{7,15}">
    </fieldset>

    <fieldset>
        <legend>Detalles</legend>

        <label for="asunto">Asunto:</label>
        <select id="asunto">
            <option>Selecciona...</option>
            <option value="consulta">Consulta</option>
        </select>

        <label>Intereses:</label>
        <input type="checkbox" value="html"> HTML
        <input type="checkbox" value="css"> CSS

        <label>Experiencia:</label>
        <input type="radio" name="exp" value="ninguna"> Ninguna
        <input type="radio" name="exp" value="basica"> Básica

        <label for="mensaje">Mensaje:</label>
        <textarea id="mensaje" rows="4"></textarea>
    </fieldset>

    <button type="submit">Enviar</button>
</form>

🧪 Ejercicio: Formulario

Crea un formulario de registro con: nombre, email, contraseña, confirmar contraseña y un botón de registro. Usa type="password" y campos required.

💡 No olvides el <label> asociado con for, usa type="password" para la contraseña y type="email" para el correo.

🖼️ Multimedia en HTML

HTML permite incrustar imágenes, audio, video y contenido externo para enriquecer tus páginas.

Ejemplo 1: Imagen con figura y leyenda

📝 Ver código de imagen con figure 
<figure>
    <img src="logo-html5.png" alt="Logo de HTML5">
    <figcaption>Logotipo de HTML5</figcaption>
</figure>

Ejemplo 2: Video

Video de demostración con controles nativos del navegador

📝 Ver código del video 
<video controls width="100%" poster="poster.jpg">
    <source src="video.mp4" type="video/mp4">
    <source src="video.ogg" type="video/ogg">
    Tu navegador no soporta el elemento de video.
</video>

Reproductor de audio con formato MP3 y OGG como fallback

Ejemplo 4: Contenido embebido (iframe)

Mapa embebido de OpenStreetMap usando <iframe>

📝 Ver código del iframe 
<iframe 
    src="https://www.openstreetmap.org/export/embed.html?..."
    width="100%"
    height="350"
    title="Mapa de la CDMX"
    allowfullscreen>
</iframe>

🧪 Ejercicio: Multimedia

Crea una galería de imágenes con 3 fotos, cada una con su <figure> y <figcaption>. Incluye un video de YouTube embebido usando <iframe>.

💡 Para YouTube: ve al video, haz clic en "Compartir" > "Insertar" y copia el código <iframe> que te dan.

🎯 Proyecto final del módulo

Combina todo lo aprendido: crea una página HTML que contenga:

  1. Un formulario de registro con nombre, email, contraseña, país (select) e intereses (checkboxes)
  2. Una tabla con los datos de los últimos 3 cursos que has tomado (fechas, nombres, duración)
  3. Al menos una imagen con <figure> y una leyenda
  4. Un video o audio embebido
  5. Uso de etiquetas semánticas como <header>, <main>, <section> y <footer>
