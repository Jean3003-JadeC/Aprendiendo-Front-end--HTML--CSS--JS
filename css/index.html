¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje que describe la presentación visual de un documento HTML. Controla colores, fuentes, espaciado, layout y diseño responsivo.

🧪 Ejercicio: Centrar un elemento

Usa los controles de arriba para centrar perfectamente el elemento #3 en el medio del contenedor. ¿Qué combinación de propiedades lo logra?

💡 Usa justify-content: center + align-items: center. O mejor aún, pon margin: auto en el elemento #3.

🧪 Ejercicio: Distribución equitativa

Configura los controles para que los 5 elementos se distribuyan con el mismo espacio entre ellos, ocupando todo el ancho del contenedor.

💡 Usa justify-content: space-between o space-evenly con flex-direction: row.

🧪 Ejercicio: Sidebar layout

Configura el grid para simular un layout con sidebar (200px) + contenido principal (ocupa el resto) + footer (abajo).

💡 Usa grid-template-columns: 200px 1fr y grid-template-rows: 1fr auto. Luego selecciona grid-column: 1 / -1 en los controles de item de arriba para que un elemento ocupe todo el ancho (como un footer).

🧪 Ejercicio: Galería de imágenes

Configura los controles para crear una galería de 4 columnas iguales con filas de 100px de alto.

💡 Usa grid-template-columns: repeat(4, 1fr) y grid-template-rows: 100px 100px.

🎯 Proyecto final del módulo

Crea una página web que incluya:

  1. Un header con navegación usando Flexbox (logo a la izquierda, menú a la derecha)
  2. Una sección de tarjetas usando CSS Grid (3 columnas responsivas)
  3. Un footer con 3 columnas usando Grid
  4. Una barra de progreso animada con CSS
  5. Todo debe ser responsivo (usa media queries)
