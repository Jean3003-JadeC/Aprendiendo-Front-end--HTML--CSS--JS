¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje que describe la presentación visual de un documento HTML. Controla colores, fuentes, espaciado, layout y diseño responsivo.

Ejemplo básico

/* Selector de etiqueta */
h1 {
    color: #0d6efd;
    font-size: 2rem;
    text-align: center;
}

/* Selector de clase */
.destacado {
    background-color: #fff3cd;
    border-left: 4px solid #ffc107;
    padding: 1rem;
}
