1. Introducción a CSS

CSS (Cascading Style Sheets) es el lenguaje que describe la presentación visual de un documento HTML.

Formas de aplicar CSS

<!-- 1. CSS en línea (inline) -->
<p style="color: blue; font-size: 16px;">Texto azul</p>

<!-- 2. CSS interno (en el <head>) -->
<style>
    p { color: blue; }
</style>

<!-- 3. CSS externo (archivo separado) -->
<link href="estilos.css" rel="stylesheet">
💡 La opción recomendada es CSS externo: separa contenido (HTML) de presentación (CSS).

2. Sintaxis Básica

Cada regla CSS tiene un selector y un bloque de declaraciones:

selector {
    propiedad: valor;
    propiedad: valor;
}

/* Ejemplo */
h1 {
    color: #1572b6;
    font-size: 2rem;
    text-align: center;
}

Unidades de medida

Absolutas
px, pt, cm, in
Relativas
%, em, rem, vh, vw
1rem = 16px (tamaño base del navegador)
100vh = toda la altura de la ventana

3. Selectores

Los selectores determinan qué elementos reciben los estilos.

SelectorEjemploSelecciona
TipopTodos los <p>
Clase.destacadoElementos con class="destacado"
ID#logoEl elemento con id="logo"
Universal*Todos los elementos
Descendentediv p<p> dentro de <div>
Hijo directodiv > p<p> hijo directo de <div>

Pseudo-clases

Se activan con una acción del usuario:

/* Pseudo-clases comunes */
a:hover { color: red; }       /* Al pasar el mouse */
input:focus { border: 2px solid blue; }  /* Al enfocar */
li:first-child { }            /* Primer hijo */
li:nth-child(odd) { }         /* Hijos impares */

4. Modelo de Caja (Box Model)

Todos los elementos HTML son cajas rectangulares. El box model describe sus partes:

margin
border
padding
content 
/* Box model completo */
.caja {
    width: 200px;
    height: 100px;
    padding: 20px;      /* Espacio interno */
    border: 2px solid black;  /* Borde */
    margin: 10px;       /* Espacio externo */
    box-sizing: border-box;  /* Incluye padding y border en el ancho */
}
💡 Siempre usa box-sizing: border-box para que el ancho/alto incluyan padding y border.

7. Posicionamiento

La propiedad position define cómo se coloca un elemento:

ValorComportamiento
staticFlujo normal (por defecto)
relativeRelativo a su posición normal
absoluteRelativo al ancestro posicionado más cercano
fixedFijo en la ventana (no se mueve al hacer scroll)
stickyHíbrido: relativo hasta que llega a un tope, luego fixed
/* Posicionamiento */
.elemento-absoluto {
    position: absolute;
    top: 20px;
    right: 0;
    z-index: 10;  /* Control de superposición */
}

.elemento-fijo {
    position: fixed;
    bottom: 20px;
    right: 20px;
}

La propiedad display controla cómo se muestra un elemento:

block inline inline inline-block none (oculto)

8. Flexbox Layout

Flexbox es un modelo de layout unidimensional que distribuye elementos en una fila o columna.

Propiedades del contenedor

  • display: flex — activa flexbox
  • flex-direction — dirección (row/column)
  • justify-content — alineación horizontal
  • align-items — alineación vertical
  • flex-wrap — salto de línea
  • gap — espacio entre elementos

Propiedades de los items

order (cambia el orden), flex-grow (crece para llenar espacio), flex-shrink (se encoge), align-self (alineación individual).

9. Grid Layout

CSS Grid es un sistema de layout bidimensional (filas y columnas simultáneamente).

.grid-container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;  /* 3 columnas iguales */
    grid-template-rows: auto;            /* filas automáticas */
    gap: 10px;                           /* espacio entre celdas */
}

10. Diseño Responsivo

El diseño responsivo adapta la página al tamaño de pantalla usando media queries.

/* Mobile-first: estilos base para móvil */
.container {
    width: 100%;
    padding: 1rem;
}

/* Tablet: a partir de 768px */
@media (min-width: 768px) {
    .container { max-width: 750px; margin: 0 auto; }
}

/* Escritorio: a partir de 1024px */
@media (min-width: 1024px) {
    .container { max-width: 960px; }
}
📱 Redimensiona esta ventana del navegador para ver cómo se adaptan los componentes.

11. Transiciones y Animaciones

Transiciones

Cambios suaves entre estados (como hover):

Ancho
Escala
.boton {
    background: blue;
    transition: all 0.3s ease;
}
.boton:hover {
    background: darkblue;
    transform: scale(1.05);
}

Animaciones con @keyframes

@keyframes pulse {
    0% { transform: scale(1); }
    50% { transform: scale(1.1); }
    100% { transform: scale(1); }
}

.elemento {
    animation: pulse 2s infinite;
}

12. Transformaciones

Las transformaciones modifican la forma, posición y tamaño de un elemento.

rotate(15deg)
scale(1.2)
translateX(20px)
skewX(-10deg)
.elemento {
    transform: rotate(45deg) scale(1.5) translate(20px, 10px);
    transform-origin: center;  /* Punto de origen de la transformación */
}

13. Variables CSS (Custom Properties)

Las variables CSS permiten reutilizar valores y crear temas fácilmente.

:root {
    --color-primario: #1572b6;
    --color-secundario: #6c757d;
    --border-radius: 8px;
    --font-size-base: 16px;
}

.boton {
    background: var(--color-primario);
    border-radius: var(--border-radius);
    font-size: var(--font-size-base);
}

/* Tema oscuro */
[data-theme="dark"] {
    --color-primario: #0d4f8b;
}
💡 Las variables CSS se heredan y pueden modificarse con JavaScript para crear temas dinámicos.
