¿Qué es Bootstrap?

Bootstrap es el framework de CSS más popular. Proporciona un sistema de grid, componentes preconstruidos (navbar, carrusel, acordeón, modales) y utilidades para crear sitios web responsivos rápida y consistentemente.

🧭 Navbar responsivo

La barra de navegación de Bootstrap es responsiva por defecto. Incluye brand, enlaces, dropdown, buscador y se colapsa en móviles.

⬆️ La navbar de arriba es funcional. Navega entre secciones y prueba el menú desplegable.

📝 Ver código del Navbar 
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container">
        <a class="navbar-brand" href="#">🅱️ Bootstrap</a>

        <button class="navbar-toggler" type="button"
                data-bs-toggle="collapse"
                data-bs-target="#navbarNav">
            <span class="navbar-toggler-icon"></span>
        </button>

        <div class="collapse navbar-collapse" id="navbarNav">
            <ul class="navbar-nav">
                <li class="nav-item">
                    <a class="nav-link active" href="#">Inicio</a>
                </li>
                <li class="nav-item dropdown">
                    <a class="nav-link dropdown-toggle" href="#"
                       data-bs-toggle="dropdown">
                        Más
                    </a>
                    <ul class="dropdown-menu">
                        <li><a class="dropdown-item" href="#">Opción</a></li>
                    </ul>
                </li>
            </ul>
        </div>
    </div>
</nav>

💡 Edita la línea <nav class="navbar navbar-expand-lg navbar-dark bg-dark"> en el HTML. Cambia navbar-dark por navbar-light y bg-dark por bg-primary.

🎠 Carrusel de imágenes

El carrusel (slider) muestra imágenes o contenido desplazable con controles, indicadores y transiciones suaves.

Navbar, cards, modales, tablas y más

📱 Diseño responsive

Sistema de grid de 12 columnas con 6 breakpoints

📝 Ver código del Carrusel 
<div id="miCarrusel" class="carousel slide carousel-fade" data-bs-ride="carousel">
    <!-- Indicadores -->
    <div class="carousel-indicators">
        <button data-bs-target="#miCarrusel" data-bs-slide-to="0" class="active"></button>
        <button data-bs-target="#miCarrusel" data-bs-slide-to="1"></button>
    </div>

    <!-- Slides -->
    <div class="carousel-inner">
        <div class="carousel-item active">
            <img src="..." class="d-block w-100" alt="...">
            <div class="carousel-caption">
                <h5>Título</h5>
                <p>Descripción</p>
            </div>
        </div>
    </div>

    <!-- Controles -->
    <button class="carousel-control-prev" data-bs-target="#miCarrusel" data-bs-slide="prev">...</button>
    <button class="carousel-control-next" data-bs-target="#miCarrusel" data-bs-slide="next">...</button>
</div>

📑 Acordeón

El acordeón muestra contenido colapsable en secciones. Solo una sección se abre a la vez (a menos que uses .accordion-flush).

Bootstrap es un framework de CSS de código abierto creado por Twitter. Proporciona una colección de herramientas, componentes y utilidades para crear interfaces web responsivas y modernas de forma rápida y consistente.

Características principales:

  • Sistema de grid responsivo de 12 columnas
  • Componentes preconstruidos (navbar, modales, cards, etc.)
  • Utilidades CSS para espaciado, colores, tipografía y más
  • Plugins JavaScript (carrusel, acordeón, tooltips, etc.)
  • Personalizable con variables Sass

Hay varias formas de personalizar Bootstrap:

  1. Variables CSS: Sobrescribe las variables de Bootstrap en tu propio CSS (--bs-primary, --bs-border-radius, etc.)
  2. Sass: Si usas Sass, puedes modificar las variables $theme-colors, $font-family-base, etc. antes de importar Bootstrap
  3. Clases de utilidad: Combina clases como bg-*, text-*, border-* para crear variaciones sin escribir CSS extra

Puedes comenzar de 3 maneras:

  1. CDN (recomendado): Agrega los enlaces a cdn.jsdelivr.net en tu HTML — como en esta misma página
  2. npm: npm install bootstrap@5.3.8 y luego importa los archivos desde node_modules
  3. Descarga: Descarga los archivos compilados desde getbootstrap.com

🪟 Ventana Modal

Los modales son cuadros de diálogo que se superponen al contenido principal.

📝 Ver código del Modal 
<!-- Botón que abre el modal -->
<button data-bs-toggle="modal" data-bs-target="#miModal">
    Abrir Modal
</button>

<!-- Estructura del modal -->
<div class="modal fade" id="miModal" tabindex="-1">
    <div class="modal-dialog modal-dialog-centered">
        <div class="modal-content">
            <div class="modal-header">
                <h5 class="modal-title">Título</h5>
                <button class="btn-close" data-bs-dismiss="modal"></button>
            </div>
            <div class="modal-body">
                Contenido del modal...
            </div>
            <div class="modal-footer">
                <button class="btn btn-secondary" data-bs-dismiss="modal">Cerrar</button>
            </div>
        </div>
    </div>
</div>

📋 Pestañas (Tabs)

📄 HTML define la estructura de la página: encabezados, párrafos, imágenes, tablas, formularios y más. Es el esqueleto de toda web.
🎨 CSS controla la apariencia: colores, fuentes, layout, animaciones y diseño responsivo. Bootstrap está construido con CSS.
⚡ JavaScript añade interactividad: eventos, manipulación del DOM, fetch API y lógica del lado del cliente. Los plugins de Bootstrap usan JS.

🅱️ Modal con data-bs-toggle

Este modal se abre usando solo atributos HTML, sin JavaScript personalizado.

Bootstrap inicializa automáticamente los modales cuando detecta data-bs-toggle="modal" y data-bs-target="#id".

💡 También puedes abrirlo con JavaScript: new bootstrap.Modal(element).show()
