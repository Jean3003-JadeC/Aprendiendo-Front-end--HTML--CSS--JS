1. Introducción a Bootstrap

Bootstrap es el framework de CSS más popular del mundo, creado por Twitter (2011). Proporciona un sistema de grid responsivo, componentes preconstruidos y utilidades CSS para crear interfaces web rápidamente.

📐
Grid Responsivo

Sistema de 12 columnas con 6 breakpoints: de móvil a pantallas grandes

🧩
Componentes

Navbar, modales, carrusel, acordeón, cards, tooltips y más

⚡
Utilidades

Clases para espaciado, colores, tipografía y flex sin escribir CSS

💡 Versiones: Bootstrap 5.3.8 es la última versión estable. Ya no depende de jQuery ni de Popper.js para componentes básicos.

2. Instalación y Configuración

Hay tres formas principales de incluir Bootstrap en tu proyecto:

☁️ CDN (recomendado)

Agrega los <link> y <script> en tu HTML. Sin descargas ni instalaciones.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
📦 npm

Para proyectos con Node.js: npm install bootstrap@5.3.8 e importa desde node_modules.

npm install bootstrap@5.3.8

// En tu JS:
import 'bootstrap/dist/css/bootstrap.min.css';
import 'bootstrap';
⬇️ Descarga

Descarga los archivos compilados desde getbootstrap.com e inclúyelos localmente.

Ir a descargas →

6. 🧭 Navbar responsivo

La barra de navegación se colapsa en móviles usando .navbar-expand-{breakpoint}. Incluye brand, enlaces, dropdown y formularios.

⬆️ La navbar de arriba es funcional. Navega entre secciones y prueba el menú desplegable.

📝 Ver código del Navbar 
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container">
        <a class="navbar-brand" href="#">🅱️ Bootstrap</a>
        <button class="navbar-toggler" data-bs-toggle="collapse" data-bs-target="#navbarNav">
            <span class="navbar-toggler-icon"></span>
        </button>
        <div class="collapse navbar-collapse" id="navbarNav">
            <ul class="navbar-nav">
                <li class="nav-item"><a class="nav-link active" href="#">Inicio</a></li>
            </ul>
        </div>
    </div>
</nav>

8. 📑 Acordeón y Tabs (Pestañas)

📂 Acordeón

Muestra contenido colapsable. Solo una sección abierta a la vez gracias a data-bs-parent.

Bootstrap es un framework CSS de código abierto creado por Twitter. Proporciona grid responsivo, componentes preconstruidos y utilidades para crear interfaces web rápidamente.

  • Sistema de grid de 12 columnas con 6 breakpoints
  • Componentes: navbar, modales, cards, carrusel, acordeón
  • Utilidades CSS para espaciado, colores, tipografía
  • Plugins JavaScript incluidos (carrusel, tooltips, etc.)
  • Personalizable con variables Sass

  1. Variables CSS: Sobrescribe --bs-primary, --bs-border-radius
  2. Sass: Modifica $theme-colors antes de importar Bootstrap
  3. Clases de utilidad: Combina bg-*, text-*, border-*

  1. CDN: Agrega <link> y <script> de jsDelivr
  2. npm: npm install bootstrap@5.3.8
  3. Descarga: Desde getbootstrap.com
📋 Pestañas (Tabs)
📄 HTML define la estructura de la página. Bootstrap usa HTML semántico con atributos data-* para activar componentes.
🎨 CSS controla la apariencia. Bootstrap está escrito en Sass con más de 1000 variables personalizables.
⚡ JavaScript añade interactividad. Los plugins JS de Bootstrap manejan modales, carrusel, acordeón y tooltips.

9. 🪟 Ventana Modal

Los modales son cuadros de diálogo que se superponen a la página. Se activan con data-bs-toggle="modal" o con JavaScript.

📝 Ver código del Modal 
<!-- Abrir -->
<button data-bs-toggle="modal" data-bs-target="#miModal">
    Abrir Modal
</button>

<!-- Estructura -->
<div class="modal fade" id="miModal" tabindex="-1">
    <div class="modal-dialog modal-dialog-centered">
        <div class="modal-content">
            <div class="modal-header">
                <h5 class="modal-title">Título</h5>
                <button class="btn-close" data-bs-dismiss="modal"></button>
            </div>
            <div class="modal-body">Contenido...</div>
            <div class="modal-footer">
                <button class="btn btn-secondary" data-bs-dismiss="modal">Cerrar</button>
            </div>
        </div>
    </div>
</div>

10. Utilidades: Espaciado, Color, Flex, Bordes
