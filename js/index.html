¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite añadir interactividad a las páginas web. Manipula el DOM, responde a eventos, se comunica con servidores y mucho más.

Temario

Consulta el archivo temario.md para ver la lista completa de temas a cubrir.

Ejemplo básico

// Mensaje en consola
console.log('¡Hola, mundo!');

// Manipulación del DOM
document.querySelector('h1').style.color = 'blue';

// Función con evento
function saludar(nombre) {
    alert(`¡Hola, ${nombre}!`);
}

Abre la consola del navegador (F12) para ver los mensajes de ejemplo.
