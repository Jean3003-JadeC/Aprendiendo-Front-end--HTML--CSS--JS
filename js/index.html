1. Introducción a JavaScript

JavaScript es el lenguaje de programación que permite añadir interactividad y lógica a las páginas web. Creado en 1995 por Brendan Eich, hoy es uno de los lenguajes más populares del mundo.

🔧 ¿Dónde se ejecuta?

🌐 Navegador

Motor V8 (Chrome), SpiderMonkey (Firefox), JavaScriptCore (Safari)

🖥️ Servidor

Node.js, Deno, Bun — JavaScript fuera del navegador

📱 Multiplataforma

Electron (escritorio), React Native (móvil)

💻 Herramientas de desarrollo

  • Consola — F12 → Console. Prueba código en tiempo real
  • Depurador — Pestaña Sources, breakpoints, paso a paso
  • ESLint — Analiza tu código en busca de errores y malas prácticas
  • Prettier — Formatea tu código automáticamente
// Tu primer código JavaScript
console.log("¡Hola, mundo!");     // Muestra en consola
console.warn("Esto es un aviso"); // Advertencia amarilla
console.error("¡Esto es error!"); // Error en rojo

➕ Operadores básicos

3. Estructuras de Control

Controlan el flujo de ejecución: ejecutar código solo si se cumple una condición, o repetirlo varias veces.

🚦 Condicionales: if / else if / else

let edad = 18;

if (edad >= 18) {
    console.log("Eres mayor de edad");
} else {
    console.log("Eres menor de edad");
}

// Operador ternario (abreviatura)
let mensaje = edad >= 18 ? "Mayor" : "Menor";

🔄 Bucles: for, while

// for: cuando sabes cuántas veces iterar
for (let i = 0; i < 5; i++) {
    console.log("Iteración:", i);
}

// while: cuando no sabes cuántas veces
let contador = 0;
while (contador < 3) {
    console.log("Contador:", contador);
    contador++;
}

🔀 switch

let dia = 3;

switch (dia) {
    case 1: console.log("Lunes");    break;
    case 2: console.log("Martes");   break;
    case 3: console.log("Miércoles"); break;
    case 4: console.log("Jueves");   break;
    case 5: console.log("Viernes");  break;
    default: console.log("Fin de semana");
}

4. Funciones

Las funciones son bloques de código reutilizable. Reciben datos de entrada (parámetros) y devuelven un resultado.

📜 Declaración de funciones

// Función tradicional
function saludar(nombre) {
    return "¡Hola, " + nombre + "!";
}

console.log(saludar("Ana")); // "¡Hola, Ana!"

// Arrow function (ES6)
const sumar = (a, b) => a + b;
console.log(sumar(5, 3));    // 8

📞 Callbacks (funciones como argumento)

function procesarUsuario(nombre, callback) {
    const mensaje = "Usuario: " + nombre;
    callback(mensaje);  // Ejecuta la función recibida
}

procesarUsuario("Ana", function(m) {
    console.log(m.toUpperCase());
});

5. Objetos

Los objetos agrupan datos (propiedades) y funciones (métodos) relacionados en una sola entidad.

📦 Crear y usar objetos

// Objeto literal
const persona = {
    nombre: "Ana",
    edad: 28,
    ciudad: "Madrid",
    saludar: function() {
        return "Hola, soy " + this.nombre;
    }
};

console.log(persona.nombre);       // "Ana"
console.log(persona["edad"]);      // 28
console.log(persona.saludar());    // "Hola, soy Ana"

🔓 Destructuración de objetos

const usuario = { id: 1, email: "ana@mail.com", rol: "admin" };

// Extraer propiedades en variables
const { email, rol } = usuario;
console.log(email); // "ana@mail.com"
console.log(rol);   // "admin"

6. Arrays

Los arrays (arreglos) almacenan listas ordenadas de datos. Pueden contener cualquier tipo de valor.

📋 Creación y métodos básicos

const frutas = ["Manzana", "Banana", "Naranja"];

console.log(frutas[0]);     // "Manzana"
console.log(frutas.length); // 3

// Mutadores (modifican el array original)
frutas.push("Uva");         // Agrega al final
frutas.pop();               // Elimina el último
frutas.unshift("Kiwi");     // Agrega al inicio

// No mutadores (devuelven nuevo array)
const copia = frutas.slice(0, 2);

🔄 Iteración: forEach, map, filter

const numeros = [1, 2, 3, 4, 5];

// forEach - ejecuta algo por cada elemento
numeros.forEach(n => console.log(n));

// map - transforma cada elemento
const dobles = numeros.map(n => n * 2);
// [2, 4, 6, 8, 10]

// filter - filtra elementos
const pares = numeros.filter(n => n % 2 === 0);
// [2, 4]

// reduce - reduce a un solo valor
const suma = numeros.reduce((acc, n) => acc + n, 0);
// 15

7. Cadenas de Texto (Strings)

Los strings representan texto. Pueden crearse con comillas simples, dobles o backticks (template literals).

📝 Template Literals

const nombre = "Ana";
const edad = 28;

// Concatenación tradicional
console.log("Me llamo " + nombre + " y tengo " + edad + " años.");

// Template literal (con backticks ``)
console.log(`Me llamo ${nombre} y tengo ${edad} años.`);
// ¡Mucho más legible!

🔧 Métodos útiles de string

const texto = "  JavaScript es genial!  ";

console.log(texto.length);           // 26
console.log(texto.trim());           // "JavaScript es genial!"
console.log(texto.toUpperCase());    // "  JAVASCRIPT ES GENIAL!  "
console.log(texto.includes("JS"));   // false
console.log(texto.startsWith("  J"));// true
console.log(texto.slice(2, 12));     // "JavaScript"

8. Manejo de Errores

Los errores son inevitables. JavaScript proporciona try...catch para manejarlos sin que rompan tu programa.

try {
    // Código que puede fallar
    let resultado = 10 / 0;
    console.log("Resultado:", resultado);

    // Lanzar nuestro propio error
    if (resultado === Infinity) {
        throw new Error("División por cero");
    }
} catch (error) {
    console.error("❌ Error:", error.message);
} finally {
    console.log("✅ Esto se ejecuta siempre");
}

📋 Tipos de error comunes

  • ReferenceError — Variable no definida
  • TypeError — Operación en tipo incorrecto
  • SyntaxError — Error de sintaxis al parsear
  • RangeError — Valor fuera del rango permitido

9. Asincronía y Promesas

JavaScript ejecuta una cosa a la vez (single-threaded), pero puede manejar operaciones que toman tiempo (APIs, archivos, timers) sin bloquear la interfaz.

⏱️ Temporizadores: setTimeout / setInterval

// Ejecuta una función después de 2 segundos
setTimeout(() => {
    console.log("¡Pasaron 2 segundos!");
}, 2000);

// Ejecuta una función cada 1 segundo
const intervalo = setInterval(() => {
    console.log("Tick...");
}, 1000);

// Para cancelar después de 5 segundos
setTimeout(() => clearInterval(intervalo), 5000);

🤝 Promesas y async/await

// Crear una promesa
const esperar = (ms) => new Promise(resolve => {
    setTimeout(() => resolve(`Esperé ${ms}ms`), ms);
});

// Usar .then()
esperar(1000).then(msg => console.log(msg));

// Usar async/await (más legible)
async function ejecutar() {
    const msg = await esperar(500);
    console.log(msg);
}

// Promise.all - ejecuta en paralelo
const todas = await Promise.all([
    esperar(1000),
    esperar(2000),
    esperar(1500)
]);

10. DOM y Eventos

El DOM (Document Object Model) es la representación del HTML como un árbol de objetos. JavaScript puede navegar, crear, modificar y eliminar elementos del DOM.

🔍 Seleccionar elementos

// Métodos de selección
const titulo = document.getElementById("miTitulo");
const secciones = document.getElementsByClassName("content-section");
const boton = document.querySelector(".btn-demo");
const todos = document.querySelectorAll("p");

// querySelector es el más flexible (usa sintaxis CSS)
const primerItem = document.querySelector(".todo-item");

✏️ Modificar elementos

const elemento = document.querySelector("h1");

// Cambiar contenido
elemento.textContent = "Nuevo título";      // Solo texto (seguro)
elemento.innerHTML = "<em>Título</em>"; // HTML (riesgo XSS)

// Cambiar estilos
elemento.style.color = "red";
elemento.style.fontSize = "2rem";

// Cambiar clases
elemento.classList.add("activo");
elemento.classList.remove("inactivo");
elemento.classList.toggle("resaltado");

🎯 Eventos

const boton = document.querySelector("#miBoton");

// Escuchar eventos
boton.addEventListener("click", function(event) {
    console.log("¡Clic!", event.target);
});

// Tipos comunes:
// click, dblclick, mouseover, mouseout
// keydown, keyup, keypress
// submit, change, input
// load, DOMContentLoaded, resize, scroll

🔄 Delegación de eventos

En lugar de agregar un listener a cada elemento, pon uno solo en el padre y usa event.target para detectar qué hijo fue cliqueado.

// Un solo listener para todos los items
document.querySelector("ul").addEventListener("click", function(e) {
    const item = e.target.closest("li");
    if (!item) return;
    console.log("Clic en:", item.textContent);
});

11. BOM y APIs Web (Fetch)

El BOM (Browser Object Model) agrupa objetos del navegador: window, location, navigator, history, localStorage y más.

📦 Web Storage: localStorage

// Guardar datos (persisten al cerrar el navegador)
localStorage.setItem("nombre", "Ana");
localStorage.setItem("tema", "JavaScript");

// Recuperar
const nombre = localStorage.getItem("nombre");

// Eliminar
localStorage.removeItem("tema");

// Limpiar todo
localStorage.clear();

🌐 Fetch API: consumir APIs externas

// GET con async/await
async function obtenerDatos() {
    try {
        const respuesta = await fetch('https://api.example.com/datos');
        if (!respuesta.ok) throw new Error('HTTP ' + respuesta.status);
        const datos = await respuesta.json();
        return datos;
    } catch (error) {
        console.error('Error:', error);
    }
}

// GET con .then()
fetch('https://api.example.com/datos')
    .then(res => res.json())
    .then(data => console.log(data))
    .catch(err => console.error(err));

12. Módulos y Buenas Prácticas

A medida que tu código crece, organizarlo en módulos es esencial para mantenerlo legible y mantenible.

📦 Módulos ES6 (import / export)

// --- archivo: utils.js ---
export function sumar(a, b) { return a + b; }
export const PI = 3.1416;

// --- archivo: main.js ---
import { sumar, PI } from './utils.js';
console.log(sumar(2, 3)); // 5

✅ Buenas prácticas

  • Usa const por defecto, let solo cuando necesites reasignar
  • Nombres descriptivos: calcularTotal en vez de ct
  • Usa camelCase para variables y funciones: miVariable
  • Comenta el por qué, no el qué (el código ya dice qué hace)
  • Mantén funciones pequeñas (máximo 20-30 líneas)
  • Usa === y !== en vez de == y !=
  • Maneja errores con try/catch en operaciones asíncronas
