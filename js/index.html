¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite añadir interactividad a las páginas web. Manipula el DOM, responde a eventos, se comunica con servidores y mucho más.

🌐 Fetch API: Generador de usuarios aleatorios

Promesas y Fetch: Obtén datos de una API real (randomuser.me) y muéstralos en pantalla.

Cargando usuario... 

// Fetch API con async/await
async function obtenerUsuario() {
    try {
        const res = await fetch('https://randomuser.me/api/');
        const data = await res.json();
        return data.results[0];
    } catch (error) {
        console.error('Error:', error);
    }
}
📝 Ver más: Promise.then vs async/await 
// Con promesas (.then)
fetch('https://api.example.com')
    .then(resp => resp.json())
    .then(data => console.log(data))
    .catch(err => console.error(err));

// Con async/await (más legible)
async function getData() {
    try {
        const resp = await fetch('https://api.example.com');
        const data = await resp.json();
        console.log(data);
    } catch (err) {
        console.error(err);
    }
}

📝 Ver código: serie vs paralelo 
// EN SERIE: una después de otra (~4.5s total)
async function enSerie() {
    const r1 = await op1();  // 1s
    const r2 = await op2();  // 2s
    const r3 = await op3();  // 1.5s
    return [r1, r2, r3];
}

// EN PARALELO: todas a la vez (~2s total)
async function enParalelo() {
    const results = await Promise.all([
        op1(),  // 1s
        op2(),  // 2s
        op3()   // 1.5s
    ]);
    return results;
}
